# 📘 Facebook Clone

A full-stack social media web application built with **Next.js**, replicating the core design and functionality of Facebook.

---

## 🚀 Features

* **User Authentication:** Sign up and log in securely (e.g., via OAuth, NextAuth, or email/password).
* **News Feed & Posts:** Create, edit, and delete text and image posts in real-time.
* **Interactions:** Like, react to, and comment on feed posts.
* **Friends System:** Send, accept, and decline friend requests.
* **User Profiles:** Customizable profiles featuring user posts, profile pictures, and cover photos.
* **Responsive UI:** Fully responsive interface matching Facebook’s light and dark mode design.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router / React)
* **Styling:** Tailwind CSS
* **Database & ORM:** Prisma / MongoDB / PostgreSQL
* **State & Data Fetching:** React Hooks / Server Actions / TanStack Query
* **Authentication:** NextAuth.js / Clerk
